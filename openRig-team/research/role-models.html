Cost vs seniority — the inversion

Dot size = output price (the iterate-heavy half of a dev loop). The expensive seat sits top-right on purpose — it buys ambiguity handling, not more code. That's why PD is escalation-only and JD owns the volume.

Anti-patterns — how this team fails

  1. Junior doing architecture — confident wrongness (weak reasoning can't see the ambiguity).
  2. Auditor rewriting code — kills independence, ships 27B-ceiling code with authority.
  3. Seniority-by-label routing — "give SE the chores" burns 2-8× budget on weak-agentic grind.
  4. Principal as normal coder — de-skills SE, bottlenecks queue.
  5. Cheapest model on ambiguous spec — LR's failure mode made visceral.
  6. Diff review without tests — rubber-stamped intent-mismatch.
  7. TM doing the work itself — queue unmanaged, briefs stop being written.
  8. Vibes-escalation — never-escalate OR over-escalate on a calendar; every brief pre-states its rung.

Accepted tradeoffs: review is a paid gate (AUD on behavior/production only — trivia = TM eyeball) · under-shaped stories always escalate up · SE always returns the falsified-hypothesis log (it is the escalation trigger's evidence).

⚠️ PD caveat — Sonnet 5.5 can silently swap models

"Anthropic reserves the right to silently swap your request to the older Sonnet 5 if it decides your prompt looks 'higher-risk.' Not refused. Not flagged. Rerouted."

For a principal-dev seat whose whole value is consistent reasoning — architecture calls, root-cause, evals, regression bisection — an invisible model swap is a landmine. "It worked yesterday" stops being a debugging lead and becomes a coin flip. Anthropic has not published the trigger criteria, so you cannot design around it.

Do this: log the model field in every response, not just the one you requested. That is the only way to catch the swap. If your PD work is deterministic-benchmark sensitive, prefer openai/gpt-5.6-sol or qwen/qwen3.8-max-0902 from the swap board (no swap behavior reported).

Why this shape

Family diversity is load-bearing for the Auditor. Self-review / self-preference bias is a known LLM failure mode — a model misses its own bugs and prefers its own style. The local auditor agent card states the rule directly: "you do NOT share the producer's assumptions; you re-derive the check." Hence Z-AI grinds, DeepSeek reasons, Alibaba judges, Anthropic principals.

Debug is why JD/SE split by shape, not seniority. Debugging = read a stack trace → reproduce → bisect → fix → regression test. JD's agentic 50.9 beats SE's 39.8 — the loop is reproduce-and-fix, and JD runs it at $0.15/$0.50. SE owns the hard reasoning (1M ctx root-cause, fix design) where the loop is a single deep thread. Route by shape or you pay 2-8× for grind.

Keep output prices low on the implementers. Debug and codegen are output-heavy. That rules out the penny-input / salty-output traps (z-ai/glm-5.3 $0.05/$7, moonshotai/kimi-k3 $0.67/$14) for SE/JD — fine as one-shot reasoners, ruinous across a debug loop.
